# ELG2538 | Circuit Analysis & Simulation (NI Multisim)

A collection of circuit simulations created using **NI Multisim** for electrical engineering coursework at the **University of Ottawa**.

> **Academic work:** Keep this repository **private** unless the course instructor authorizes publication of assessed work. Do not upload lab manuals, assignment solutions, or collaborators' files publicly without permission.

## Circuit topics

| Folder | Lab manual title | Source designs |
|---|---|---|
| `01-Resistive-Circuit-Measurements/` | **Mesures dans les circuits résistifs** (Resistive Circuit Measurements) | `Design1.ms14` – `Design5.ms14` |
| `02-Resistor-Networks-Thevenin-Oscilloscope/` | **Réseaux de résistances, théorème de Thévenin et bases de l'oscilloscope** (Resistor Networks, Thévenin's Theorem & Oscilloscope Basics) | `Design1.ms14` – `Design3.ms14` |

Folder titles follow the supplied laboratory manual headings. Individual schematic functions have **not** been inferred from the binary `.ms14` files.

## Open a design

1. Install a compatible version of **NI Multisim**.
2. Open a `.ms14` file in either topic folder.
3. Run the simulation and inspect the schematic and readings.
